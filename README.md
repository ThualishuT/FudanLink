# FudanLink

轻量的复旦大学校园网认证工具，支持自动连接、后台保活、开机启动和系统托盘，默认使用有线网络。

**当前版本：1.3.1**

## 安装与更新

运行环境：64 位 Windows 11，.NET Framework 4.8。

1. 运行发布包中的 `FudanLinkSetup.exe`，在 Windows 管理员权限提示中选择“是”。
2. 安装完成后，双击发布包中的 `FudanLink` 快捷方式，或运行 `C:\Program Files\FudanLink\FudanLink.exe`。
3. 首次使用时打开“设置”，填写 UIS 账号和密码，确认连接方式后点击“保存设置”。

更新时，先从托盘菜单选择“退出”，再运行新版安装器。更新会保留已保存的账号、密码和设置；完成后重新打开程序。

## 连接校园网

主界面显示当前认证状态。未连接时，点击中央电源图标连接；已连接时，再次点击可断开。

打开“自动连接”后，程序会在确认离线时尝试重新认证，并在网络变化或电脑唤醒后检查连接。手动断开会暂停自动重连；需要恢复时，再次点击电源图标，或重新启用自动连接。

“刷新状态”用于立即检查当前连接。关闭自动连接不会主动断开已有连接；如需注销校园网，请点击中央电源图标。

## 托盘与开机启动

关闭或最小化主窗口后，程序会隐藏到系统托盘并继续运行。双击托盘图标可重新打开面板；图标被收起时，可在任务栏的隐藏图标区域找到。

右键托盘图标，可打开面板、进入设置、暂停或启用自动连接，以及退出程序。

在“设置”中打开“开机启动”并保存，程序会在当前 Windows 用户登录后静默启动。自动连接仍受主界面的开关和手动断开状态控制。

## 设置

| 选项 | 说明 |
| --- | --- |
| 账号 | 用于校园网认证的 UIS 账号。 |
| 密码 | 留空可保留已保存的密码；更换账号时必须填写对应密码。 |
| 连接方式 | 默认为“有线网络”。仅在需要使用无线校园网时选择“WLAN”。程序不会自动从有线切换到 WLAN。 |
| 开机启动 | 控制当前 Windows 用户登录后是否自动启动程序。 |
| 查看日志 | 打开本机运行记录所在文件夹，便于排查连接问题。 |

修改设置后，点击“保存设置”使其生效。

## 常见问题

**一直显示“等待校园网络”或无法连接**

检查网线、网卡状态及所选连接方式，确认已接入校园网络，然后点击“刷新状态”。

**显示“需要处理认证”**

检查 UIS 账号、密码及校园网账号状态。更正后保存设置，再尝试连接。

**手动断开后没有自动重连**

这是预期行为。点击电源图标连接，或重新启用自动连接，即可恢复。

**Clash Verge 开启 TUN 后节点超时**

若同时开启了 Windows 移动热点或网络共享，可先关闭热点／共享后重试。认证服务应保持直连；FudanLink 不会自动修改代理配置或系统路由。

## 本机数据

程序安装在 `C:\Program Files\FudanLink`。账号、设置和日志保存在当前用户的 `%LOCALAPPDATA%\FudanNetLite` 文件夹；密码使用 Windows 当前用户加密保护。

退出程序会停止后台检查和保活，不会主动注销校园网。若要断开当前认证连接，请先在主界面点击电源图标，再退出。
